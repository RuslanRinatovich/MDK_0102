## 📚 О курсе

Добро пожаловать на курс **"Поддержка и тестирование программных модулей"** для специальности **09.02.07 Информационные системы и программирование**.

Этот репозиторий содержит все материалы для изучения дисциплины: лекции, практические работы, задания и тесты. Мы отказались от традиционных презентаций в пользу современного формата Markdown с интерактивными диаграммами.

## 🎯 Цели курса

- Сформировать понимание роли тестирования в жизненном цикле ПО
- Научиться применять различные методы и техники тестирования
- Освоить инструменты документирования тестов
- Подготовиться к самостоятельной работе в IT-командах
